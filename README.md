# SmartCare

## An Intelligent Caregiver Scheduling and Compliance Management System

SmartCare is a web-based decision-support prototype designed for home-care organizations.

The system centralizes caregiver availability, qualifications, compliance status, client care requirements, and scheduling information.

SmartCare uses a transparent rule-based suitability scoring method to recommend potentially suitable caregivers for scheduled shifts.

Final caregiver assignment decisions remain under authorized human control.

## Project Objectives

- Centralize caregiver information
- Track caregiver qualifications and availability
- Track compliance status
- Manage client care requirements
- Identify scheduling conflicts
- Recommend potentially suitable caregivers
- Explain matching factors
- Maintain auditability of important actions

## Privacy and Security

SmartCare will use simulated, non-identifiable data for the capstone prototype.

The system is not intended to store or process real protected health information.

Security considerations include authentication, role-based access control, input validation, secure password handling, data minimization, and audit logging.
